Deploy di GitHub Pages

  1. Buat repository GitHub, lalu unggah file ini dengan nama index.html di folder utama.
  2. Buka Settings → Pages → Build and deployment.
  3. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
  4. Buka URL yang diberikan GitHub setelah deployment selesai.

Penyimpanan & backup

Media dan draf disimpan di IndexedDB browser ini, tidak diunggah ke GitHub. Data tidak otomatis berpindah perangkat atau tersinkron dengan Story Studio versi ChatGPT. Menghapus data situs dapat menghapus draf. Ekspor backup berkala; file backup memuat media dan catatanmu, jadi simpan secara pribadi. Jangan unggah backup ke repository publik.

Untuk posting otomatis

GitHub Pages hanya menyajikan halaman statis. Diperlukan backend terpisah yang mengautentikasi pemilik, menyimpan token dengan aman, menyediakan media untuk layanan publikasi, dan memasukkan jadwal ke Metricool atau menjalankan penjadwal Meta. Koneksi Metricool di ChatGPT tidak otomatis tersedia pada halaman ini. Jangan menempelkan password, access token, atau API key ke HTML.

Rencana waktu tidak memicu publikasi atau notifikasi otomatis, baik ketika tab terbuka maupun tertutup. Tidak ada Story yang dianggap terjadwal ke Instagram hanya karena tersimpan di sini.
